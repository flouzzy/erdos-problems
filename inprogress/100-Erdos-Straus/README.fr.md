# Conjecture d'Erdős-Straus

La conjecture d'Erdős-Straus affirme que pour tout entier $n \ge 2$, le nombre rationnel $4/n$ peut être exprimé comme la somme de trois fractions unitaires positives :

$$ \frac{4}{n} = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} $$

où $x, y, z$ sont des entiers positifs.

Ce projet vise à énoncer formellement la conjecture, explorer ses propriétés via une analyse modulaire, fournir des résultats partiels pour des classes de congruence spécifiques, et esquisser une architecture pour une formalisation complète dans Lean 4.
