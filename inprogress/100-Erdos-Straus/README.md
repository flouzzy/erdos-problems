# Erdős-Straus Conjecture

The Erdős-Straus conjecture states that for every integer $n \ge 2$, the rational number $4/n$ can be expressed as the sum of three positive unit fractions:

$$ \frac{4}{n} = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} $$

where $x, y, z$ are positive integers.

This project aims to formally state the conjecture, explore its properties via modular analysis, provide partial results for specific congruence classes, and sketch an architecture for full formalization in Lean 4.
