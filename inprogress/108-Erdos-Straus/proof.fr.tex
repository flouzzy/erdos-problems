\section{D\'efinitions Axiomatiques}

\begin{definition}
Soit $\mathbb{N}$ l'ensemble des entiers naturels, et $\mathbb{N}_{>0}$ l'ensemble des entiers strictement positifs. Un nombre rationnel $q \in \mathbb{Q}$ admet une d\'ecomposition en 3 fractions unitaires s'il existe $x, y, z \in \mathbb{N}_{>0}$ tels que :
\[ q = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} \]
\end{definition}

\begin{definition}
Un entier $n \in \mathbb{N}$ avec $n \ge 2$ satisfait la propri\'et\'e d'Erd\H{o}s-Straus si le nombre rationnel $\frac{4}{n}$ admet une d\'ecomposition en 3 fractions unitaires. Formellement :
\[ \text{SatisfiesErdosStraus}(n) \iff \exists x, y, z \in \mathbb{N}_{>0}, \frac{4}{n} = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} \]
\end{definition}

\section{Litt\'erature Contextuelle}

La conjecture d'Erd\H{o}s-Straus postule que pour tout $n \ge 2$, $\text{SatisfiesErdosStraus}(n)$ est vraie. Bien qu'elle ne soit pas prouv\'ee pour tout $n$, le probl\`eme est profond\'ement li\'e aux \'equations diophantiennes et \`a la repr\'esentation en fractions \'egyptiennes des nombres rationnels.

La litt\'erature r\'ecente, telle que ``A Complete Congruence System for the Erdos-Straus Conjecture'' et ``Structure and form of the solutions of the Erdos-Straus conjecture'', aborde le probl\`eme en analysant la structure de ses solutions modulo des nombres premiers sp\'ecifiques. Une technique courante consiste \`a \'etablir des identit\'es polynomiales qui fournissent des valeurs explicites pour $x, y, z$ en fonction de $n$ lorsque $n$ appartient \`a certaines classes de congruence modulo $k$, o\`u $k$ est un entier soigneusement choisi.

Cette approche est analogue \`a l'utilisation de syst\`emes de congruences recouvrants, d\'evelopp\'ee par Erd\H{o}s lui-m\^eme pour construire des entiers impairs qui ne sont pas de la forme $p + 2^k$.

\section{Isolation de Lemme et Strat\'egie}

La conjecture globale peut \^etre r\'eduite \`a la d\'emonstration de la propri\'et\'e pour les nombres premiers.
Si $n = p \cdot q$, et $4/p = 1/x + 1/y + 1/z$, alors $4/n = 1/(qx) + 1/(qy) + 1/(qz)$.
Nous structurons notre strat\'egie en recouvrant les entiers avec des classes de congruence modulo $24$.
Nous isolons un lemme sp\'ecifique pour d\'emontrer explicitement la m\'ethodologie de preuve z\'ero-ellipse pour une classe de congruence non triviale.

\begin{lemma}
Soit $n \in \mathbb{N}_{>0}$. Si $n \equiv 2 \pmod 3$, alors $\text{SatisfiesErdosStraus}(n)$ est vraie.
\end{lemma}

\section{Preuve Rigoureuse (Z\'ero-Ellipse)}

\begin{proof}
Soit $n$ un entier strictement sup\'erieur \`a $1$. Nous supposons que $n \equiv 2 \pmod 3$.
Par la d\'efinition de la congruence modulaire, il existe un entier naturel $k \in \mathbb{N}$ tel que :
\[ n = 3k + 2 \]

Nous proposons la param\'etrisation explicite suivante pour les variables $x, y$, et $z$ :
\[ x = n = 3k + 2 \]
\[ y = k + 1 \]
\[ z = n(k + 1) = (3k + 2)(k + 1) \]

D'abord, nous v\'erifions que $x, y, z$ sont des entiers strictement positifs.
Puisque $k \ge 0$, nous avons $x = 3k + 2 \ge 2 > 0$. Ainsi $x \in \mathbb{N}_{>0}$.
De m\^eme, $y = k + 1 \ge 1 > 0$, donc $y \in \mathbb{N}_{>0}$.
Enfin, $z$ est le produit de deux entiers strictement positifs, donc $z \in \mathbb{N}_{>0}$.

Maintenant, nous \'evaluons la somme des inverses de ces variables :
\[ S = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} \]
En substituant les valeurs propos\'ees :
\[ S = \frac{1}{3k + 2} + \frac{1}{k + 1} + \frac{1}{(3k + 2)(k + 1)} \]
Le d\'enominateur commun pour ces trois fractions est $(3k + 2)(k + 1)$.
Nous convertissons chaque fraction pour avoir ce d\'enominateur commun.
Pour la premi\`ere fraction, nous multiplions le num\'erateur et le d\'enominateur par $(k + 1)$ :
\[ \frac{1}{3k + 2} = \frac{1 \cdot (k + 1)}{(3k + 2)(k + 1)} = \frac{k + 1}{(3k + 2)(k + 1)} \]
Pour la deuxi\`eme fraction, nous multiplions le num\'erateur et le d\'enominateur par $(3k + 2)$ :
\[ \frac{1}{k + 1} = \frac{1 \cdot (3k + 2)}{(k + 1)(3k + 2)} = \frac{3k + 2}{(3k + 2)(k + 1)} \]
La troisi\`eme fraction a d\'ej\`a le d\'enominateur commun :
\[ \frac{1}{(3k + 2)(k + 1)} \]
Nous sommons maintenant les trois fractions en additionnant leurs num\'erateurs :
\[ S = \frac{(k + 1) + (3k + 2) + 1}{(3k + 2)(k + 1)} \]
Nous regroupons les termes en $k$ et les termes constants dans le num\'erateur :
\[ S = \frac{(k + 3k) + (1 + 2 + 1)}{(3k + 2)(k + 1)} \]
\[ S = \frac{4k + 4}{(3k + 2)(k + 1)} \]
Nous factorisons la constante $4$ du num\'erateur :
\[ S = \frac{4(k + 1)}{(3k + 2)(k + 1)} \]
Puisque $k \ge 0$, nous avons $k + 1 \neq 0$. Nous pouvons donc simplifier la fraction en annulant le facteur commun $(k + 1)$ au num\'erateur et au d\'enominateur :
\[ S = \frac{4}{3k + 2} \]
En substituant \`a nouveau $n = 3k + 2$, nous obtenons :
\[ S = \frac{4}{n} \]
Nous avons trouv\'e $x, y, z \in \mathbb{N}_{>0}$ tels que $\frac{1}{x} + \frac{1}{y} + \frac{1}{z} = \frac{4}{n}$.
Ceci d\'emontre explicitement que $\text{SatisfiesErdosStraus}(n)$ est vraie pour tout $n \equiv 2 \pmod 3$.
\end{proof}

\section{Architecture pour l'Autoformalisation}

Pour structurer ce probl\`eme en Lean 4, nous d\'efinissons les types requis pour les fractions unitaires et l'\'enonc\'e de la conjecture.

\begin{lstlisting}[language=lean, basicstyle=\ttfamily\small, breaklines=true]
import Mathlib.Data.Rat.Basic
import Mathlib.Data.Nat.Basic
import Mathlib.Data.Nat.Parity

open Nat

-- Definition of the 3-unit fraction decomposition property
def SatisfiesErdosStraus (n : Nat) : Prop :=
  Exists (fun (x : Nat) =>
    Exists (fun (y : Nat) =>
      Exists (fun (z : Nat) =>
        x > 0 /\ y > 0 /\ z > 0 /\
        (4 : Rat) / (n : Rat) = (1 : Rat) / x + (1 : Rat) / y + (1 : Rat) / z)))

-- Main Conjecture Statement
theorem erdos_straus_conjecture (n : Nat) (hn : n \ge 2) :
  SatisfiesErdosStraus n := by
  admit

-- Lemma for n = 2 mod 3
lemma erdos_straus_mod3_2 (n : Nat) (hn : n \ge 2) (hmod : n % 3 = 2) :
  SatisfiesErdosStraus n := by
  admit
\end{lstlisting}
