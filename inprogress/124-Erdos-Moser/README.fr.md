# Équation d'Erdős-Moser

[🇬🇧 English Version](README.md)

Ce répertoire contient les recherches et travaux en cours pour résoudre l'équation d'Erdős-Moser : $1^k + 2^k + \dots + (m-1)^k = m^k$.

## Statut : En cours

L'effort actuel se concentre sur la combinaison d'approximations analytiques avec des valuations $p$-adiques pour restreindre les solutions possibles. Une architecture préliminaire de formalisation pour Lean 4 a également été rédigée pour faciliter les preuves vérifiées par ordinateur.

### Fichiers
- `124-Erdos-Moser.pdf` : Preuve informelle détaillée (Anglais).
- `124-Erdos-Moser-fr.pdf` : Preuve informelle détaillée (Français).
- `generate_tex.py` : Script Python utilisé pour générer et compiler dynamiquement les preuves.
