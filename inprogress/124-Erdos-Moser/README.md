# Erdős-Moser Equation

[🇫🇷 Version Française](README.fr.md)

This directory contains research and ongoing work toward solving the Erdős-Moser equation: $1^k + 2^k + \dots + (m-1)^k = m^k$.

## Status: In Progress

The current effort focuses on combining analytic approximations with $p$-adic valuations to restrict the possible solutions. A preliminary formalization architecture for Lean 4 has also been drafted to facilitate computer-verified proofs.

### Files
- `124-Erdos-Moser.pdf`: Detailed informal proof (English).
- `124-Erdos-Moser-fr.pdf`: Detailed informal proof (French).
- `generate_tex.py`: Python script used to dynamically generate and compile the proofs.
