# 140-Erdos-Collatz

This directory contains research on the Collatz Conjecture, famously noted by Paul Erdős as a problem for which "mathematics is not yet ready."

The conjecture asserts that taking any positive integer $n$ and applying the rule $n \mapsto n/2$ (if $n$ is even) or $n \mapsto 3n+1$ (if $n$ is odd) will eventually reach 1.

## Status
In progress. The current approach involves rigorous topological structure analysis, probabilistic heuristics for stopping times, and formalizing the sequence within proof assistants.
