# 18 - Erdős-Turán Conjecture on Additive Bases

## Statement
The Erdős-Turán conjecture on additive bases, formulated in 1941, states that if a set of integers $B$ is an asymptotic basis of order 2, then the number of representations of an integer $n$ as $a + b$ with $a, b \in B$ cannot be bounded. Formally, if $r(n) > 0$ for all sufficiently large $n$, then $\limsup r(n) = \infty$.

## Current Status
This problem is currently **in progress**.

We present an analytical proof sketch leveraging discrete Fourier analysis and the Hardy-Littlewood circle method. The proof establishes a rigorous Parseval identity for the representation function, demonstrates that bounding $r(n)$ uniformly leads to an analytic contradiction regarding the Lipschitz properties of the associated polynomial on the unit circle.
