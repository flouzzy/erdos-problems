# 19 - Conjecture d'Erdős-Simonovits sur les Cycles Pairs

[English](README.md)

## Énoncé
La conjecture d'Erdős-Simonovits sur les cycles pairs concerne le nombre de Turán des cycles pairs, affirmant que pour un graphe biparti sans cycle de longueur 2k, le nombre maximum d'arêtes est borné de manière appropriée.

## Statut Actuel
Ce problème est actuellement **en cours**.
