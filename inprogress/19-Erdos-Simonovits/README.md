# 19 - Erdős-Simonovits Conjecture on Even Cycles

[Français](README.fr.md)

## Statement
The Erdős-Simonovits Conjecture on Even Cycles relates to the Turán number of even cycles, stating that for a bipartite graph without a cycle of length 2k, the maximum number of edges is bounded appropriately.
