# 33 - Erdős Unit Distance Problem

The **Erdős Unit Distance Problem** asks for the maximum number of unit distances that can exist among a set of $n$ points in the Euclidean plane.
Paul Erdős proved in 1946 that this number is $O(n^{1 + c/\log \log n})$ and conjectured that this upper bound is tight.
Currently, the best known upper bound is $O(n^{4/3})$, achieved independently by Spencer, Szemerédi, and Trotter in 1984 using the Crossing Lemma.

## Current Status

This problem is currently in progress. An architectural proof sketch using polynomial partitioning and the Crossing Lemma is being formalized.
