# Erdős Conjecture on Arithmetic Progressions

The Erdős conjecture on arithmetic progressions, often referred to as the Erdős-Turán conjecture, states that if the sum of the reciprocals of the members of a set $A$ of positive integers diverges, then $A$ contains arithmetic progressions of any given length.

This directory contains a partial resolution of the problem, focusing on specific lemmas related to density increments, Bohr sets, and Gowers norms, structured towards a formal proof in Lean 4.

## Structure
- `42-Erdos-Arithmetic-Progression.tex`: Detailed informal proof of the selected lemmas.
- `42-Erdos-Arithmetic-Progression.pdf`: Compiled document of the proof.
