# Problem 55: Erdős-Straus Conjecture

**Status:** In Progress (Partial Resolution)
**Field:** Diophantine Equations / Number Theory

The Erdős-Straus conjecture (1948) states that for all integers $n \ge 2$, the rational number $4/n$ can be expressed as the sum of three positive unit fractions. That is, there exist positive integers $x, y$, and $z$ such that:

$$ \frac{4}{n} = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} $$

This folder contains a comprehensive mathematical proof sketch and structural analysis of the conjecture. We demonstrate the problem using explicit constructive modular proofs for various congruence classes and empirical algebraic construction for initial values.
