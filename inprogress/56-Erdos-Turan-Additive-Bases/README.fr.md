# Conjecture d'Erdős-Turán sur les bases additives

Ce répertoire contient des recherches sur la conjecture d'Erdős-Turán concernant les bases additives.
La conjecture stipule que si une base asymptotique d'ordre 2 existe pour les entiers naturels, alors le nombre de représentations de $n$ comme somme de deux éléments de la base ne peut pas être borné.

## Progrès Actuels

- La génération de la preuve formelle et l'architecture d'autoformalisation sont en cours.
- Des stratégies de preuves zéro-ellipse et des approches probabilistes sont explorées.
