# Erdős-Graham Conjecture (Problem 66)

The Erdős-Graham conjecture on Egyptian fractions posits that if the integers greater than 1 are colored with a finite number of colors, then there must exist a monochromatic subset whose sum of reciprocals is exactly 1.

## Current Status
This folder contains the ongoing research towards formalizing a proof framework. The preliminary structure outlines combinatorial bounds leveraging density theories and a translation of the problem into a Lean 4 verifiable architecture.

- `66-Erdos-Graham.pdf`: Analytical framework and zero-ellipse proof sketch (English).
- `66-Erdos-Graham.tex`: LaTeX source file.
