# 72 - Erdős-Straus Conjecture

The Erdős-Straus conjecture posits that for every integer $n \geq 2$, the rational number $4/n$ can be expressed as the sum of three positive unit fractions. That is, there exist positive integers $x, y, z$ such that:

$$ \frac{4}{n} = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} $$

This directory contains research, partial solutions, and proof attempts towards resolving this conjecture. It is currently placed in `inprogress/` as the conjecture remains largely open in its full generality, though validated for a very large number of cases.

## Documentation

The detailed step-by-step rigorous mathematical proof and analysis can be found in the associated PDF document `72-Erdos-Straus.pdf`.
