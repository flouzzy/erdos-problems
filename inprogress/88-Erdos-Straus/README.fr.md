# 88 - Conjecture d'Erdős-Straus

## Énoncé

La conjecture d'Erdős-Straus énonce que pour tout entier $n \geq 2$, le nombre rationnel $4/n$ peut s'écrire comme la somme de trois fractions unitaires :

$$ \frac{4}{n} = \frac{1}{x} + \frac{1}{y} + \frac{1}{z} $$

où $x, y, z$ sont des entiers strictement positifs.
