# 44 - Erdős Discrepancy Problem

[Français](README.fr.md)

## Statement
The Erdős discrepancy problem, posed by Paul Erdős in 1932, concerns the properties of infinite sequences of $+1$ and $-1$. It asks whether for any sequence $(x_n)_{n=1}^\infty$ with $x_n \in \{-1, +1\}$ and for any constant $C > 0$, there exist integers $k$ and $d$ such that the absolute value of the sum $\sum_{i=1}^k x_{i \cdot d}$ is strictly greater than $C$.
