# Erdős-Graham Conjecture (Problem 66)

The Erdős-Graham conjecture on Egyptian fractions posits that if the integers greater than 1 are colored with a finite number of colors, then there must exist a monochromatic subset whose sum of reciprocals is exactly 1.

## Current Status
This conjecture has been **resolved**. It was proven by Ernest Croot (published in the Annals of Mathematics in 2003, with preprints circulating around 2000).

This folder contains the formal documentation of the resolution and its verifiable architecture in Lean 4.

- `66-Erdos-Graham.pdf`: Analytical framework and proof of resolution (English).
- `66-Erdos-Graham.tex`: LaTeX source file.

## References
